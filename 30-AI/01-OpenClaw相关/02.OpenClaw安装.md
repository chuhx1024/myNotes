## assistant

既然是前端程序员，那安装 OpenClaw 对你来说应该非常顺手。我们直接上“专业版”安装流程，不搞那些花里胡哨的，确保环境干净、依赖准确。

核心思路是：Homebrew 管理依赖 -> 安装 Node.js 22+ -> 一键脚本部署 -> 配置 API Key。

以下是为你定制的安装指南：

🛠️ 第一阶段：环境准备 (Node.js)

OpenClaw 强依赖 Node.js 环境，且版本要求较高（≥22）。作为前端，你肯定有 nvm 或 fnm，如果没有，建议直接用 Homebrew 安装最新版，避免权限问题。
打开终端 (Terminal)
安装 Node.js
    推荐使用 Homebrew 安装 Node.js 22 或更高版本（LTS）：
    # 如果没装 Homebrew，先装它：/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    
    brew install node@22
验证版本
    确保版本符合要求（npm 版本也会随之更新）：
    node -v  # 需显示 v22.x.x 或更高
    npm -v

前端特别注意：
如果你是 Apple Silicon (M1/M2/M3) 芯片，请务必确认 Node.js 是 ARM64 架构，而不是通过 Rosetta 运行的 x64 版本。
检查命令：node -p "process.arch"，输出必须是 arm64。

🦐 第二阶段：安装 OpenClaw

官方提供了一键安装脚本，这是最稳妥的方式，它会自动处理二进制文件和路径配置。
执行安装脚本
    在终端直接运行：
    curl -fsSL https://openclaw.ai/install.sh | bash
    (注：如果网络较慢，脚本可能会卡住，请确保网络通畅)
加载环境变量
    安装完成后，为了让终端能识别 openclaw 命令，需要刷新一下环境变量（脚本通常会自动提示，但手动执行更保险）：
    source ~/.zshrc
验证安装
    输入以下命令，看到版本号即代表成功：
    openclaw --version

⚙️ 第三阶段：初始化配置 (Onboarding)

安装好只是第一步，作为开发者，我们需要配置 API Key 才能让它“转”起来。
启动向导
    输入命令进入交互式配置：
    openclaw onboard
关键配置步骤 (避坑指南)
    终端会进入问答模式，请参照以下建议操作：
Security warning: 选 Yes（确认知晓风险）。
Onboarding mode: 选 QuickStart（快速启动）。
Model/Auth Provider: 这里选择你常用的模型提供商。
如果你有 OpenAI Key，选 OpenAI。
如果你用 火山引擎 (豆包) 或 阿里云百炼，选择对应的选项或 Custom Provider。
API Key: 粘贴你的 API Key。
Default Model: 选择或输入具体的模型 ID（例如 gpt-4o 或 doubao-seed-2-0-pro）。
Select channel: 暂时选 Skip for now（先不接微信/飞书，先在本地终端调试）。
Configure skills: 建议选 Yes，安装基础技能（如文件操作、提醒等）。
Enable hooks: 建议全选或按需选择（如 session-memory 可以让它拥有长期记忆）。

🚀 第四阶段：启动与使用

配置完成后，你有两种方式开始使用：
方式 A：Web UI (推荐新手)
    启动 Gateway 后，终端会输出一个带 Token 的本地网址（通常是 http://127.0.0.1:18789/?token=xxxx）。在浏览器打开这个链接，你就能看到一个类似 ChatGPT 的界面，这是调试 Prompt 最方便的地方。
启动命令：openclaw gateway start
方式 B：终端 TUI
    如果你喜欢极客范儿，直接在终端输入：
    openclaw tui
    即可在命令行里和它对话。

💡 常见问题排查 (Troubleshooting)
command not found: openclaw
    这说明环境变量没生效。检查 ~/.zshrc 文件，确保里面有导出 ~/.local/bin 或 npm 全局路径的配置。
    # 手动修复路径示例
    echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
    source ~/.zshrc
安装依赖报错 (sharp/node-llama-cpp)
    如果在安装过程中遇到 sharp 或 node-llama-cpp 编译错误（常见于 M 芯片），可以尝试设置环境变量忽略全局 libvips：
    SHARP_IGNORE_GLOBAL_LIBVIPS=1 npm install -g openclaw@latest
配置文件位置
    作为前端，你可能想手动修改配置。主配置文件位于：
    ~/.openclaw/openclaw.json
    你可以用 VS Code 直接打开修改，比如更换模型或调整 API 地址。
