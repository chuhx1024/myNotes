## user

怎么自己写一个Skill？

## assistant

既然你是前端程序员，那写 Skill 对你来说简直就是降维打击。

正如我们刚才聊的，Skill 本质上就是一个带配置文件的 npm 包或脚本。你不需要学习复杂的 AI 模型训练，你只需要写“业务逻辑代码”（JS/TS/Shell/Python），然后写一份“接口文档”（Markdown）告诉 AI 怎么用这个代码就行了。

开发一个 Skill 只需要三个核心文件。我们用最符合你技术栈的 TypeScript/Node.js 方式来演示，手把手带你写一个“统计项目代码行数”的 Skill。

🛠️ 第一步：初始化项目结构

在你的电脑上找个顺眼的地方（比如 ~/Projects），新建一个文件夹：

mkdir openclaw-skill-counter
cd openclaw-skill-counter
npm init -y
npm install typescript @types/node --save-dev
npx tsc --init

📝 第二步：编写核心逻辑 (index.ts)

这是 Skill 的“肉体”。OpenClaw 调用 Skill 时，会通过标准输入（stdin）传递 JSON 数据，你的程序需要读取它，处理后通过标准输出（stdout）返回 JSON。

新建 index.ts：

import * as fs from 'fs';
import * as path from 'path';

// 定义输入参数的类型
interface InputParams {
  dirPath: string;
}

// 简单的递归统计函数
function countLines(dir: string): number {
  let count = 0;
  const files = fs.readdirSync(dir);

  for (const file of files) {
    const fullPath = path.join(dir, file);
    const stat = fs.statSync(fullPath);

    if (stat.isDirectory()) {
      // 跳过 node_modules 和 .git
      if (file !== 'node_modules' && file !== '.git') {
        count += countLines(fullPath);
      }
    } else if (file.endsWith('.ts') || file.endsWith('.js')) {
      const content = fs.readFileSync(fullPath, 'utf-8');
      count += content.split(/\r\n|\r|\n/).length;
    }
  }
  return count;
}

// 主入口：读取 stdin -> 处理 -> 输出 stdout
async function main() {
  try {
    // 1. 读取 stdin (OpenClaw 传过来的 JSON)
    const stdin = fs.readFileSync(0, 'utf-8');
    const params: InputParams = JSON.parse(stdin);

    // 2. 执行业务逻辑
    const totalLines = countLines(params.dirPath);

    // 3. 返回结果给 OpenClaw (必须是 JSON 格式)
    const result = {
      status: 'success',
      message: 统计完成,
      data: {
        path: params.dirPath,
        lines: totalLines
      }
    };
    
    console.log(JSON.stringify(result));

  } catch (error: any) {
    // 错误处理
    console.log(JSON.stringify({
      status: 'error',
      message: error.message
    }));
  }
}

main();

记得运行 npx tsc 把它编译成 dist/index.js。

📄 第三步：编写“说明书” (SKILL.md)

这是 Skill 的“灵魂”。AI 看不懂你的代码，它只看这个 Markdown 文件来决定什么时候调用你以及怎么调用你。

新建 SKILL.md：

name: project-counter
description: 当用户需要统计某个目录下的代码行数时使用。特别是前端项目，需要排除 node_modules。

项目代码行数统计工具

作用
统计指定目录下所有 .ts 和 .js 文件的总行数。

使用场景
用户问：“这个项目有多少行代码？”
用户想评估项目规模。

参数说明
dirPath (string, 必填): 要统计的目录绝对路径。

执行方式
调用 node dist/index.js，通过 stdin 传入 JSON 参数。

返回格式
成功返回 JSON：{ "status": "success", "data": { "lines": 1234 } }
失败返回 JSON：{ "status": "error", "message": "..." }

📦 第四步：配置 manifest (plugin.json)

为了让 OpenClaw 识别它，你需要一个简单的配置文件（类似 package.json 的元数据版）。

新建 plugin.json：

{
  "name": "project-counter",
  "version": "1.0.0",
  "description": "统计前端项目代码行数",
  "author": "Your Name",
  "skills": [
    {
      "action": "count-code-lines",
      "description": "统计指定目录下的代码行数",
      "parameters": [
        {
          "name": "dirPath",
          "type": "string",
          "required": true,
          "description": "目录的绝对路径"
        }
      ]
    }
  ]
}

🚀 第五步：安装与测试
安装
    把你写好的这个文件夹，直接复制（或软链接）到 OpenClaw 的 Skills 目录：
    # 假设你的 OpenClaw 安装在默认位置
    cp -r ~/Projects/openclaw-skill-counter ~/.openclaw/skills/
热重载
    OpenClaw 会自动监听这个目录。你不需要重启网关，它通常几秒钟后就能识别到新 Skill。
实战测试
    打开 OpenClaw 的 Web 界面，输入：
    > “帮我看看 /Users/yourname/Projects/my-react-app 这个目录下大概有多少行代码？”

    AI 的思考过程（你可以强制它显示出来）：
用户想统计代码行数。
检测到 project-counter 这个 Skill。
提取路径参数 /Users/yourname/Projects/my-react-app。
执行命令：node dist/index.js (传入路径)。
拿到返回值：{ "lines": 5432 }。
回答用户：“这个项目大约有 5432 行代码。”

💡 前端程序员的“作弊码”

如果你觉得写 TypeScript 太麻烦，只想快速验证想法，OpenClaw 支持纯 Shell 脚本模式。

你可以只写一个 run.sh：
!/bin/bash
读取 stdin
read input
简单处理
echo "收到路径：$input，正在统计..."
返回 JSON
echo '{"status": "success", "data": "模拟数据"}'
然后在 SKILL.md 里告诉 AI：“执行 bash run.sh”。

总结：
写 Skill 就是写接口。
Input: JSON (用户意图参数化)
Logic: 你的 TS/JS/Shell 代码
Output: JSON (执行结果)
Doc: Markdown (给 AI 看的注释)
